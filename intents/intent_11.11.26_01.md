# Задача: Публикация сборки APK для писателей

## Четкие шаги
1. [v] Проверить успешное создание файла `app-debug.apk` после сборки.
2. [v] Переместить готовый `.apk` в корень проекта, переименовав его в удобное для писателей имя (например, `bookwriter-android-v1.0.apk`).
3. [v] Добавить путь к исходным тяжелым бинарникам в `.gitignore`, чтобы они случайно не попали в коммит.
4. [v] Обновить файл `01-git-changelog.md` — добавить в него блок с инструкцией для писателей, где взять этот файл (или загрузить его в GitHub Releases, если настроен удаленный доступ).

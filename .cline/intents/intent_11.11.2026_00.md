# Задача: Добавление поддержки Android (.apk) в текущий Swift-проект

## Контекст и цель
Мы хотим сохранить текущие наработки на Swift для iOS, но расширить проект так, чтобы в этой же директории можно было собирать `.apk` файл для Android. Для этого мы превратим проект в кроссплатформенный, используя подход с общим кодом.

## Четкие шаги (Что сделать)
1. [ ] Изучить файлы `Chapter.swift` и `TextProcessingService.swift`, чтобы выделить чистую бизнес-логику, не связанную с интерфейсом.
2. [ ] Создать структуру для Android-версии приложения в этом же репозитории (добавить папку `android/` и конфигурационные файлы Gradle).
3. [ ] Написать UI для Android (на Jetpack Compose / Kotlin), полностью повторяющий логику экранов из папки `Views/Main/`.
4. [ ] Настроить проект так, чтобы из него можно было независимо собирать как iOS-версию, так и Android-версию (.apk).

## Ограничения и правила
- Не удалять и не ломать существующий рабочий код Swift.
- **[Важно] Проводить строгую очистку кода: своевременно удалять все недостижимые функции, неиспользуемые переменные, импорты и неиспользуемые классы как в старом, так и в новом коде.**
- Разделять платформозависимый код (UI) и общую логику.

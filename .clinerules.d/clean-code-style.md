# 🧹 СТИЛЬ И ОРГАНИЗАЦИЯ КОДА SWIFT
- **Модификаторы доступа:** Все свойства внутри `View` и вспомогательные методы в классах, которые не используются снаружи, должны быть строго помечены как `private`.
- **Использование разделов `// MARK: -`:** Каждый файл крупнее 100 строк должен быть четко разбит на логические блоки с помощью комментариев-меток: `// MARK: - Properties`, `// MARK: - Initialization`, `// MARK: - Methods`.
- **Очистка за собой:** При остановке или уничтожении сервисов (например, остановка записи голоса) обязательно зануляй буферы, останавливай `AVAudioEngine` и сбрасывай стейт.

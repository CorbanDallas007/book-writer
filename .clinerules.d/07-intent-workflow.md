# 07. Процесс работы через файлы Интентов

## Поиск и обнаружение
- Перед началом выполнения любой новой задачи или изменения кода ВСЕГДА проверяй корень проекта на наличие файлов, соответствующих маске `intent_DD.MM.YYYY_NN.md`.
- Формат даты: DD.MM.YYYY — текущий день (например, 11.11.2026).
- Формат номера: NN — порядковый номер задачи за день (например, 01, 02).

## Процесс выполнения
- Строго следуй шагам, описанным в самом свежем и актуальном файле интента.
- Не выполняй скрытых или не описанных в интенте глобальных изменений, кроме базовой очистки кода по правилу `06-clean-code-style.md`.
- По мере продвижения по задаче обновляй markdown-чекбоксы `[ ]` на `[v]` прямо в активном файле интента, чтобы фиксировать текущий прогресс.

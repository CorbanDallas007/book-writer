# 📐 АРХИТЕКТУРА И ЧИСТОТА КОДА
- Строго соблюдай паттерн MVVM / Clean Architecture. Запрещен бизнес-код внутри SwiftUI `View`.
- Все обновления UI во ViewModel должны происходить строго на `@MainActor`.
- Никаких принудительных извлечений (`!`). Используй `if let` или `guard let`.
- Один файл — одна сущность или экран.

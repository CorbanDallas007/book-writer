# CLAUDE.md — Правила проекта book-writer (обязательно к исполнению)

Перед началом任何 работы с этим проектом **прочти все файлы в директории `.clinerules/`** и следуй им без исключений. Эти файлы являются обязательным кодексом проекта.

## 📋 Файлы правив (.clinerules/)

| Файл | Описание |
|------|----------|
| `.clinerules/architecture.md` | MVVM / Clean Architecture, запрет бизнес-кода в View, `@MainActor`, нет `!`, один файл — одна сущность |
| `.clinerules/clean-code-style.md` | Модификаторы доступа `private`, `// MARK: -` секции, очистка ресурсов, удаление мертвого кода, предкоммитная ревизия |
| `.clinerules/git-changelog.md` | Атомарные коммиты, формат `Log XXX: [Описание]`, лог-файлы в `.cline-logs/`, инструкция по APK |
| `.clinerules/intent-workflow.md` | Поиск интентов в `intents/`, выполнение шагов из интента, обновление чекбоксов, обновление `README.md` |
| `.clinerules/optimization.md` | Точечные изменения (Diff-Only), без рефакторинга без команды, лаконичность в чате |
| `.clinerules/safe-data-lifecycle.md` | `[weak self]` в замыканиях, валидация ввода, Alert при удалении из БД |
| `.clinerules/ui-ux-guidelines.md` | SF Symbols, Dark Mode, адаптивная верстка, тактильный отклик (Haptics) |

## 🔴 Обязательные правила (кратко)

1. **Всегда читай `.clinerules/` перед работой** — эти файлы имеют высший приоритет.
2. **MVVM / Clean Architecture** — бизнес-логика не в SwiftUI View / Compose.
3. **Нет принудительных извлечений (`!`)** — используй `if let` / `guard let` / safe calls.
4. **Один файл — одна сущность или экран.**
5. **Приватные модификаторы** — все внутренние свойства и методы помечай как `private`.
6. **`// MARK: -` секции** — файлы >100 строк разбивай на логические блоки.
7. **Удаляй мертвый код** — не оставляй закомментированный код «на будущее».
8. **Предкоммитная ревизия** — перед каждым `git commit` проведи аудит: временные файлы, сиротские файлы, бинарники.
9. **Атомарные коммиты** — одна задача = один коммит, формат `Log XXX: [Описание на русском]`.
10. **Логи в `.cline-logs/`** — создавай `log-001.md` при завершении этапа.
11. **Обновляй `README.md`** после завершения всех пунктов интента.
12. **Точечные изменения** — Diff-Only, не переписывай целый файл ради одной строки.
13. **`[weak self]` в замыканиях** — предотвращай retain cycles.
14. **Валидация ввода** — проверяй текст на пустоту перед сохранением в БД.
15. **Alert при удалении из БД** — подтверждение действия пользователем.
16. **SF Symbols** — только системные иконки Apple.
17. **Dark Mode** — системные цветовые токены.
18. **Адаптивная верстка** — без хардкода размеров.
19. **Haptics** — тактильный отклик на ключевые кнопки.
20. **Android-специфика:** `AudioRecord` освобождай, JNI/C++ память освобождай, стейт сбрасывай.

## 📂 Структура проекта

```
book-writer/
├── .clinerules/          # Обязательные правила (прочти перед любой работой)
├── intents/              # Файлы задач (intent_DD.MM.YY_NN.md)
├── .cline-logs/          # Логи завершённых этапов (log-001.md, ...)
├── ARCHITECTURE.md       # Техническая архитектура проекта
├── README.md             # Описание проекта и инструкция по сборке
└── android/              # Android-приложение (Kotlin + C++/JNI)
```

## ⚠️ Если какое-то правило противоречит другому

Приоритет: `.clinerules/` > `ARCHITECTURE.md` > `README.md` > другой код/документация.

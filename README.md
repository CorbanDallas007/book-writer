# 📚 book-writer — Автономный ИИ-Ассистент Писателя (iOS + Android)

**book-writer** — это кроссплатформенное приложение для авторов и писателей, разработанное для мгновенного захвата потока мыслей и превращения устной речи в чистый, структурированный текст.

Приложение работает **100% локально и автономно** на обеих платформах. Оно не использует внешние облачные API, не требует интернета и не отправляет ваши тексты на сторонние серверы, гарантируя полную конфиденциальность вашего творчества.

## 🔥 Ключевые возможности (Killer-Features)

### На iOS:
1. **Синхронная диктовка на лету:** Текст появляется на экране прямо во время вашей речи благодаря глубоким нейросетевым моделям Apple Speech Framework.
2. **Умный оффлайн-редактор:** Встроенный движок на базе `NaturalLanguage` автоматически очищает наговоренный текст от слов-паразитов (*"ну"*, *"короче"*, *"типа"*, *"в общем"*), исправляет регистр и расставляет пунктуацию.
3. **Локальный словарь Лёра (Книга Памяти):** Вы можете внести в специальные базы имена персонажей или названия вымышленных локаций. Локальный ИИ будет сверяться с ними, чтобы никогда не коверкать специфические термины вашей книги при транскрибации.
4. **Стилистические режимы обработки:**
   * 📝 *Дословно* (Чистый текст "как есть" с исправленной орфографией).
   * ✍️ *Литературный стиль* (Сглаживание резких речевых оборотов для художественного текста).
   * 📌 *Черновик идеи* (Превращение монолога в удобный структурированный список тезисов).
5. **Дерево глав (Scrivener-style):** Возможность раскидывать наговоренные заметки по папкам и привязывать их к конкретным главам книги.
6. **Быстрый экспорт:** Встроенная поддержка системного Share Sheet для мгновенного сохранения черновиков в формате `.txt` или передачи на ПК.

### На Android:
7. **Полная поддержка диктовки:** Синтез речи и распознавание speech-to-text с использованием Google Speech API или собственных нейросетей.
8. **Умная очистка текста:** Аналог iOS-фичи — удаление слов-паразитов, исправление регистра и пунктуации.
9. **Синхронизация лора/персонажей:** Общая база имен и терминов между платформами.
10. **Экспорт и импорт:** Возможность сохранять файлы `.txt` и `.md`, а также передавать их между устройствами через Share интерфейса.

## 🛠️ Технологический стек

### На iOS:
* **Язык разработки:** Swift 5.10+
* **Интерфейс:** SwiftUI (Современная декларативная верстка)
* **База данных:** SwiftData (Локальное реактивное хранение данных, iOS 17+)
* **Транскрибация речи:** `SFSpeechRecognizer` (Локальный движок Apple с поддержкой Apple Neural Engine)
* **Лингвистический анализ:** `NaturalLanguage` Framework (`NLTagger`, `NLTokenizer`)

### На Android:
* **Язык разработки:** Kotlin 1.9+
* **Интерфейс:** Jetpack Compose (Современный нативный declarative UI)
* **База данных:** Room (Локальное релятивное хранение данных)
* **Транскрибация речи:** Android Speech-to-Text API
* **Лингвистический анализ:** Пользовательский движок на базе Kotlin

### Общие для обеих платформ:
* **Архитектура:** MVVM (Model-View-ViewModel)
* **ИИ-модель:** Локальные сети на базе `qwen2.5-coder:14b` (запуск на устройстве)
* **Конфиденциальность:** 100% локальная обработка данных, ничего не уходит в облако

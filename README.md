# 📚 book-writer — Автономный ИИ-Ассистент Писателя (iOS)

**book-writer** — это современное iOS-приложение для авторов и писателей, разработанное для мгновенного захвата потока мыслей и превращения устной речи в чистый, структурированный текст.

Приложение работает **100% локально и автономно**. Оно не использует внешние облачные API, не требует интернета и не отправляет ваши тексты на сторонние сервера, гарантируя полную конфиденциальность вашего творчества.

---

## 🔥 Ключевые возможности (Killer-Features)

1. **Синхронная диктовка на лету:** Текст появляется на экране прямо во время вашей речи благодаря глубоким нейросетевым моделям Apple Speech Framework.
2. **Умный оффлайн-редактор:** Встроенный движок на базе `NaturalLanguage` автоматически очищает наговоренный текст от слов-паразитов (*"ну"*, *"короче"*, *"типа"*, *"в общем"*), исправляет регистр и расставляет пунктуацию.
3. **Локальный словарь Лёра (Книга Памяти):** Вы можете внести в специальную базу имена персонажей или названия вымышленных локаций. Локальный ИИ будет сверяться с ними, чтобы никогда не коверкать специфические термины вашей книги при транскрибации.
4. **Стилистические режимы обработки:**
    * 📝 *Дословно* (Чистый текст "как есть" с исправленной орфографией).
    * ✍️ *Литературный стиль* (Сглаживание резких речевых оборотов для художественного текста).
    * 📌 *Черновик идеи* (Превращение монолога в удобный структурированный список тезисов).
5. **Дерево глав (Scrivener-style):** Возможность раскидывать наговоренные заметки по папкам и привязывать их к конкретным главам книги.
6. **Быстрый экспорт:** Встроенная поддержка системного Share Sheet для мгновенного сохранения черновиков в формате `.txt` или передачи на ПК.

## 🛠️ Технологический стек

* **Язык разработки:** Swift 5.10+
* **Интерфейс:** SwiftUI (Современная декларативная верстка)
* **База данных:** SwiftData (Локальное реактивное хранение данных, iOS 17+)
* **Транскрибация речи:** `SFSpeechRecognizer` (Локальный движок Apple с поддержкой Apple Neural Engine)
* **Лингвистический анализ:** `NaturalLanguage` Framework (`NLTagger`, `NLTokenizer`)

## 🚀 Требования и Запуск

1. **Минимальная версия ОС:** iOS 17.0 или новее.
2. **Среда разработки:** Xcode 15.0+ (на macOS).
3. **Разрешения устройства:** При первом запуске приложение запросит доступ к **Микрофону** и **Распознаванию речи**. Без этих разрешений функция диктовки работать не сможет.

### Как запустить локально:
1. Склонируйте репозиторий: `git clone https://github.com`
2. Откройте папку проекта в Xcode.
3. Выберите целевое устройство (Ваш iPhone или симулятор с поддержкой iOS 17+).
4. Нажмите **Run** (`Cmd + R`).
